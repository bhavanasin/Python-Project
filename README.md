Student Grade Manager (CLI)
Overview
This is a simple command-line program built in Python to help keep track of student grades and quickly calculate their averages. I split the code into a couple of files to keep things organized. It uses basic OOP (a class for the students), dictionaries to map subjects to scores, and a standard while loop to handle the interactive menu.

Environment Setup
Python 3.x
A standard terminal or command prompt

Dependency Installation
You don't need to pip install anything for this to work. It only uses built-in Python standard libraries.

Configuration
No extra setup, API keys, or environment variables are needed to run this.

Execution
Here is how you can run the project on your machine:
1. First, clone this repository to your computer by running:
   `git clone https://github.com/bhavanasin/python-project.git`
2. Next, open your terminal and go into the project folder:
   `cd python-project`
3. Start the program by running:
   `python main.py`
4. Once it starts, just follow the on-screen prompts (type a number from 1 to 5 to navigate the menu and press Enter).
